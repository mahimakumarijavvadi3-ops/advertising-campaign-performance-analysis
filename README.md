# Advertising Campaign Performance Analysis

## Project Overview

This project analyzes digital advertising campaign data using R to understand campaign performance, identify important marketing patterns, and support data-driven decisions.

The analysis follows a structured workflow covering data validation, exploratory analysis, predictive modeling, key business insights, and statistical testing.

## Project Objectives

- Validate and clean advertising campaign data
- Explore campaign performance and marketing KPIs
- Analyze CTR, CPC, conversion rate, and ROAS
- Identify relationships between advertising variables
- Build a predictive model for campaign performance
- Perform statistical tests to support analytical findings
- Translate analytical results into practical business recommendations

## Analysis Workflow

1. **Data Validation and Cleaning**  
   Checks data types, missing values, duplicate records, and invalid numeric values.

2. **Exploratory Data Analysis**  
   Examines campaign metrics using summary statistics, distributions, correlations, and visualizations.

3. **Predictive Modeling**  
   Builds a regression-based model to understand and predict campaign performance.

4. **Key Insights**  
   Converts analytical results into clear business findings and actionable recommendations.

5. **Statistical Testing**  
   Uses statistical tests and p-values to determine whether observed relationships are statistically meaningful.

## Key Performance Metrics

The project focuses on important advertising metrics such as:

- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Conversion Rate
- Revenue
- Return on Ad Spend (ROAS)
- Campaign spend
- Impressions
- Clicks
- Conversions

## Tools and Technologies

- **R**
- Base R statistical functions
- Data visualization
- Statistical analysis
- Regression modeling

## Reproducible Workflow

The R scripts are organized in sequence so that the analysis can be followed from data validation through statistical testing and business interpretation.

## Outcome

The final analysis provides a structured view of advertising campaign performance and demonstrates how statistical analysis and predictive modeling can be used to turn campaign data into practical marketing insights.
